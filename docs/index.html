Chrome Extension

Windchill PowerTools

A lightweight browser overlay for Windchill users who need faster JCA debugging, easier access to system health tools, and quick log triage without changing the Windchill server.

Privacy Policy GitHub Repository Contact Praveen Sampath

Core Features

JCA Debug Toggle

Turn jcaDebug=true on and off directly from the overlay.

JS Debug Toggle

Turn jsDebug=true on and off without editing the URL manually.

Parsed JCA Details

Hover Windchill debug-marked UI items and parse component details such as component IDs, builders, data builders, row-height settings, and related debug metadata.

Copy Parsed Output

Copy the current parsed JCA block as JSON for sharing, debugging, or support.

Operational Tools

System Health Shortcuts

Open standard Windchill JMX tools such as Server Status, Cache Statistics, Log Viewer, Top SQL, Cluster Stack Traces, and more from one expandable section.

Error Stack Trace Copy

On Windchill log viewer pages, copy the visible error stack trace without interpreting the log.

PTC Support Link

Open the static PTC Support page directly from the overlay.

Need Help?

Quick access to Praveen Sampath by email for Windchill and PLM support discussions.

User Experience

  • Starts as a movable round launcher instead of a full panel
  • Expandable responsive panel for desktop and smaller screens
  • Draggable launcher and panel header
  • Dark and light theme toggle with persisted preference
  • Remembers open/closed state and last position after refresh

How It Works

  • Runs only on Windchill pages matching *://*/Windchill/*
  • Reads JCA debug information already present on the page
  • Processes visible log content locally in the browser
  • Stores only local preferences such as theme, panel position, and open/closed state
  • Does not require Windchill server modifications
