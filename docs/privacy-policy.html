Windchill PowerTools Privacy Policy

Last updated: April 10, 2026

Windchill PowerTools is a Chrome extension published by Plural Technology. This privacy policy explains what the extension accesses, how it uses data, and what data is and is not transmitted outside the user’s browser.

1. What the extension accesses

The extension runs only on Windchill pages that match *://*/Windchill/*.

When used on those pages, the extension may access:

  • Windchill page content needed to display the overlay inside Windchill
  • JCA debug metadata shown on the page when jcaDebug=true is enabled
  • Visible log text on Windchill log viewer pages for on-page log analysis
  • Extension preferences stored locally, such as theme, panel position, and open/closed state

2. How the extension uses data

The extension uses the accessed data only to provide its features, including:

  • Showing the floating PowerTools widget on Windchill pages
  • Toggling jcaDebug and jsDebug in the Windchill URL
  • Parsing and displaying visible JCA debug information
  • Analyzing visible Windchill log content locally in the browser
  • Generating shortcut links and resolution search links for user convenience
  • Saving local UI preferences in Chrome storage

3. Data sharing and transmission

Windchill PowerTools does not sell personal data. Windchill PowerTools does not transmit parsed page content, debug details, or log content to Plural Technology servers.

When the user clicks external links generated by the extension, such as Google, PTC Support, PTC Community, the Plural Technology website, or email links, the browser navigates to those third-party destinations at the user’s request.

4. Local storage

The extension stores limited preferences locally in Chrome storage, such as:

  • Selected theme
  • Widget position
  • Whether the panel is open or closed

These preferences are used only to improve the user experience inside the extension.

5. Personal information

The extension itself does not require account creation and does not collect user email addresses automatically. If a user chooses to contact Plural Technology using a mail link, that communication is handled by the user’s email provider.

6. Security

The extension is designed to process Windchill page content locally in the user’s browser. Users should avoid sharing sensitive data outside their organization unless they choose to do so.

7. Changes to this policy

This privacy policy may be updated from time to time. Any updates will be reflected on this page.
